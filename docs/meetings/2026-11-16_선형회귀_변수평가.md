# 11/16 공유 자료: 선형 회귀 학습 정리와 변수 조합 평가 (박정우)

"치수를 모를 때" 추천(#5)에 쓰는 회귀 모델을 그래프로 정리하고, 키·몸무게에 무엇을 더 물으면 정확해지는지 평가한 자료입니다.
문서와 발표 파일만 추가했고 코드는 바꾸지 않았습니다. **앱에는 아무것도 반영하지 않았습니다 — 무엇을 반영할지는 팀이 정합니다.**

| 파일 | 내용 |
|---|---|
| `FitCheck_선형회귀_학습_1116.pptx` (12장) | 11/9에 학습한 회귀(키·몸무게 → 어깨·가슴·허리)를 그래프 8장으로 설명. 학습 곡선, 오차 분포, 체형·나이별 오차 |
| `FitCheck_변수별_모델평가_1116.pptx` (9장) | 나이·신발·바지·브라 밴드를 하나씩 더했을 때의 정확도 비교 |
| `FitCheck_변수5개_모델평가_1116.pptx` (8장) | 후보 7개의 모든 조합(모델 90개) 비교 → 변수 5개 이내에서 가장 정확한 모델 |

모든 장에 발표자 노트(대본)가 있습니다.

## 요약

데이터는 #5와 같습니다: 사이즈코리아 8차(2020) 직접측정 5,092명, 088 어깨사이너비 · 042 젖가슴둘레 · 045 허리둘레, seed 42로 80/20 분할.

**1. 선형 회귀 학습 정리**
- 평균만 찍기 대비 오차(평가용 20%): 가슴 남 5.11 → 2.35cm · 여 6.66 → 2.55cm, 허리도 절반 이하. 어깨는 약 20%만 줄어듭니다(R² 0.32~0.34).
- 학습 인원을 160명으로 줄여도 전체로 배운 것과 0.04cm 이내입니다. 남은 오차는 데이터 부족이 아니라 **입력 부족**입니다. #6 에서 MLP로 바꿔도 같았던 것과 같은 이야기입니다.
- 나이가 식에 없어서 허리 예측이 연령 구간에 따라 최대 3~4cm 치우칩니다.

**2. 변수 조합 평가** — 일치율 = 실제 치수를 넣은 `size_fit.recommend` 와 같은 사이즈를 고른 비율 (평가용 1,019명 × 치수표 9개, #5의 "한 점"과 같은 정의)

| 입력 | 전체 일치율 | 비고 |
|---|---|---|
| 키·몸무게 (#5) | 84.2% | #5 본문의 값과 일치 |
| + 나이 | 85.8% | 허리 오차 남 3.35 → 2.73 · 여 3.00 → 2.57cm (#6 결과와 같은 방향) |
| + 신발 사이즈 | 84.0% | 효과 없음 |
| + 바지 사이즈 | 91.0% | 하의 남 82.6 → 97.6 · 여 72.6 → 94.5%. 상의는 거의 그대로 |
| 남: + 바지 / 여: + 바지 + 브라 밴드·컵 | 92.0% | 변수 5개 이내에서 가장 정확 (남 87.5 · 여 95.7%) |
| 참고: + 바지 + 줄자로 가슴둘레 한 곳 | 97.8% | 줄자 없는 방식의 천장과 비교용 |

- **남자 상의는 81.5 → 82.5%에서 멈춥니다.** 나이·신발·목둘레·모자 사이즈 중 무엇을 더해도 0.3%p 이내입니다. 이 구간은 줄자 한 곳 요청(#5)이나 "입혀 보고 판단"이 맡아야 합니다.
- 여자는 브라 밴드와 컵을 같이 넣으면 가슴 오차가 2.71 → 1.15cm로 줄어듭니다.

## 한계 (낮춰 읽어야 하는 이유)

- **바지·브라 사이즈 수치는 상한입니다.** 실제 허리·가슴 치수를 표기 단위(1인치, 5cm, 2.5cm)로 반올림해 넣었습니다. 사람이 말하는 표기 사이즈는 브랜드·착용 습관에 따라 실제 치수와 다릅니다. 팀원 실측으로 확인이 필요합니다.
- 키·몸무게를 틀리게 말하는 오차는 넣지 않았습니다.
- 정답은 "치수를 알 때의 추천"이지 실제로 입어서 맞는지가 아닙니다.
- 원자료의 연령 코드(1~10)가 나이순 구간이라는 것은 추정입니다. 통계정보보고서에서 확인이 필요합니다.
- 확률 추천(60% 기준)은 새 변수로 다시 돌리지 않았습니다. 위 수치는 예측값 한 점 기준입니다.
- 학습 곡선 · 체형/나이별 오차 · 변수 평가는 11/16에 새로 돌린 분석입니다. 스크립트는 개인 작업 폴더에 있고 이 PR에는 넣지 않았습니다(필요하면 따로 올리겠습니다).
