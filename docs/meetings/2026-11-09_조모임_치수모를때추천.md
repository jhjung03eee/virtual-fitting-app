## 1. 왜 이 주제인가

지금 앱은 사용자가 줄자로 잰 치수(어깨·가슴 등)를 넣어야 사이즈를 추천한다.
하지만 대부분의 사용자는 자기 치수를 모른다.
그래서 다른 서비스와 연구가 이 문제를 어떻게 풀었는지 9가지 사례를 같은 틀로 비교했다.
비교한 항목은 네 가지다: 무엇을 입력받는지, 어떻게 추정하는지, 무엇을 출력하는지, 어떤 데이터가 필요한지.

## 2. 사례 9개와 우리 활용 추천도

추천도는 두 가지를 함께 봤다: 지금 우리 데이터로 만들 수 있는가, 그리고 교수님 주문에 얼마나 직접 답하는가.

| 추천도 | 사례 | 핵심 | 우리가 가져올 것 |
|---|---|---|---|
| ★★★★★ | 유니클로 MySize ASSIST | 성별·나이·키·몸무게·선호 핏으로 사이즈 추천 | 같은 입력 구성. 결과를 베이스라인으로 비교 |
| ★★★★★ | Bartol 외, *Sensors* 2022 | 키·몸무게 선형 회귀가 딥러닝과 비슷한 성능 (doi:10.3390/s22051885) | 같은 방법을 사이즈코리아(한국인) 데이터로 적용 → 핵심 엔진 후보 |
| ★★★★☆ | 무신사 실측 비교 | 몸 대신 "전에 산 옷"과 상품 실측을 비교 | "잘 맞는 내 옷 1벌 재기" 입력. 재는 법 안내 |
| ★★★★☆ | Fit Analytics · ASOS | 비슷한 사람의 반품 데이터 활용. "만족할 확률 %" 표시 | 확률 표시, 체형 그림 질문 |
| ★★★☆☆ | Amazon (RecSys 2017, WWW 2018) | 고객·상품의 "숨은 사이즈" → 작다/맞다/크다 확률 | 착용 피드백으로 보정하는 수식 |
| ★★★☆☆ | Zalando (RecSys 2018) | 계층 베이즈. 데이터가 적으면 상위 평균에 기댐 | 확률·범위 추천의 학술 근거 |
| ★★★☆☆ | 에이블리 | 키·체중·평소 사이즈 + 구매 데이터 | 국내 입력 습관. 실측표와 추천을 한 화면에 |
| ★★☆☆☆ | True Fit | 브랜드 간 사이즈 정규화 DB | "평소 사이즈"가 강한 단서라는 점 |
| ★★☆☆☆ | 3DLOOK | 정면·측면 사진 2장 → 치수 측정, 자이로로 각도 통제 | 사진 측정은 보조 단계. 각도 통제 아이디어 |

**결론**: 큰 회사들은 구매·반품 빅데이터로 푼다.
우리는 그런 데이터가 없으므로 다음 세 가지로 간다.
- 공개 인체치수 통계(사이즈코리아)
- 상품 치수표
- 확률 표현

## 3. 사례에서 반복되는 패턴 → 우리 앱에 넣는 방법

1. **키·몸무게(+나이)로 시작한다.** 사이즈코리아로 회귀식을 만들면 처음 쓰는 사용자도 추천받을 수 있다.
2. **"평소 사이즈"나 "잘 맞는 내 옷"이 강한 단서다.** 이것을 두 번째 입력 단계로 둔다.
3. **확신도와 다른 사이즈의 핏도 같이 보여준다.** 사이즈별로 맞을 확률을 보여주고, 경계에 걸리면 "L·XL 사이"라고 안내한다.
4. **작다/맞다/크다 피드백으로 점점 개인화한다.** 입어 본 결과로 추정값을 보정한다.

## 4. 오늘 모임 진행안 (3시간)

| 시간 | 내용 |
|---|---|
| 0:00–0:15 | 지난주 공유, 오늘 목표 합의 |
| 0:15–0:45 | 실착 기록지 확정: 상의 총장·어깨·가슴, 착용감(작다/맞다/크다), 평소 고르는 사이즈 |
| 0:45–1:45 | **실측·실착 (핵심)**: 줄자로 2회 측정 → M·L·XL을 입어 보고 기록, 정면 사진 |
| 1:45–2:00 | 휴식, 기록을 CSV로 입력 |
| 2:00–2:30 | 기준 적중률 측정: 현재 추천 규칙(가슴 +5·어깨 +0.5)을 4명에게 적용 → 본인 선택과 일치율 |
| 2:30–2:50 | 다음 주 분담: 조경숙 교수님 자문, 예외 처리(박정우·이은재, 사이즈코리아), 다른 체형 섭외 |
| 2:50–3:00 | 적중률과 분담표를 단톡에 공유 |

**오늘 결과물 목표**
- 기준 적중률 표 1장 (4명 × 3사이즈)
- 틀린 사례의 원인 (문제 카드)
- 다음 주 분담표

## 5. 팀이 정할 것 (토의 질문)

1. 첫 입력을 유니클로처럼 성별·나이·키·몸무게·선호 핏으로 할까?
2. "평소 사이즈 / 잘 맞는 옷"을 두 번째 단계로 넣을까?
3. 결과를 사이즈 하나로 줄까, ASOS처럼 확률과 경계까지 보여줄까?
4. 정확도 비교 기준(베이스라인)을 무엇으로 할까? 예: 유니클로 MySize ASSIST 결과 vs 우리 결과

**바로 해 볼 수 있는 것**
- 4명이 유니클로 MySize ASSIST에 키·몸무게를 넣고, 나온 사이즈를 실착 결과와 비교 → 첫 베이스라인
- 에이블리·무신사 사이즈 추천도 같은 사람으로 써 보기
- 사이즈코리아 원자료 신청 방법 확인 (sizekorea.kr)
- Bartol 외 공개 코드로 키·몸무게 → 치수 회귀를 먼저 돌려 보고, 사이즈코리아 데이터로 바꿔 비교
