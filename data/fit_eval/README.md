# 사이즈 추천 검증 데이터 (팀원 착용 기록)

사이즈 추천이 실제 착용감을 몇 % 맞히는지 재기 위한 기록이다. 결과는 `python scripts/eval_size_fit.py`로 본다.

**몸 치수는 개인정보라 커밋하지 않는다.** 실제 기록 파일 `people.csv`·`garments.csv`는 `.gitignore`에 들어 있다.
아래 `*_template.csv`를 복사해서 채운다. 엑셀로 열고 저장할 때는 **CSV UTF-8** 형식으로 저장한다.

## people.csv — 한 사람당 한 줄

| 칸 | 내용 |
|---|---|
| person | 이름 대신 쓸 짧은 ID (예: p1). garments.csv와 같아야 한다 |
| height_cm | 키 |
| shoulder_cm | 어깨너비 (폭) |
| chest_circumference_cm / waist_circumference_cm | 가슴·허리 **둘레** |

추천은 **신체 치수만** 쓰므로 이 파일이 꼭 있어야 한다. 상의는 가슴(또는 어깨), 하의는 허리가 없으면 그 사람 옷은 측정에서 빠진다.

## garments.csv — 가진 옷 한 벌당 한 줄

| 칸 | 내용 |
|---|---|
| person | people.csv의 ID |
| garment | 옷 이름 (예: 무지 반팔티 카키 M) |
| category | `upper`(상의) 또는 `lower`(하의) |
| material | 소재·종류를 짧게: `면티`, `셔츠`, `니트`, `데님`, `슬랙스` 등. 같은 종류끼리 비교할 때 쓴다 |
| shoulder, chest, length | 상의: 어깨너비·가슴단면·총장 |
| waist, length | 하의: 허리단면·총장 |
| felt | 입었을 때 느낌: **`작음` / `맞음` / `큼`** 중 하나 |
| note | 자유 메모 (예: 가슴은 맞는데 기장이 김) |

**옷 재는 법:** 바닥에 평평하게 펴고 줄자로 잰다(단면). 쇼핑몰 치수표와 같은 방법이다.
- 가슴단면: 양쪽 겨드랑이 바로 아래 끝에서 끝까지
- 어깨너비: 어깨 솔기 끝에서 끝까지
- 총장: 뒷목 아래(목 뒤 시접)부터 밑단까지
- 허리단면: 허리 밴드 위쪽 끝에서 끝까지 (단추 잠근 상태)
- 하의 총장: 허리 밴드 위쪽부터 밑단까지 (바깥 솔기를 따라)

사이즈 판정은 **상의 총장·어깨·가슴, 하의 총장·허리**만 쓴다(2026-10-26 결정). 다른 항목은 재지 않아도 된다.

**레귤러핏 옷만 넣는다.** 추천이 레귤러핏 옷 기준이라, 처음부터 크게 나온 오버핏 디자인은 빼거나 material 칸에 `오버핏`이라고 적는다.
`felt`는 그 옷을 입었을 때 사이즈가 작음 / 맞음 / 큼 중 어디인지 적는다. `맞음`만 있으면 측정이 안 되니 **`작음`·`큼`도 섞는다**
(작아진 옛 옷, 잘못 산 옷, 가족 옷). 목표: 4명 × 상의 4벌 + 하의 3벌 ≈ 28벌.
