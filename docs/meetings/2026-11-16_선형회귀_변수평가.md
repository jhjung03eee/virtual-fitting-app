문서와 발표 파일만 추가했고 코드는 바꾸지 않았습니다. **앱에는 아무것도 반영하지 않았습니다 — 무엇을 반영할지는 팀이 정합니다.**

| 파일 | 내용 |
|---|---|
| `FitCheck_선형회귀_학습_1116.pptx` (13장) | 11/9에 학습한 회귀(키·몸무게 → 어깨·가슴·허리)를 그래프로 설명. 몸의 어디를 예측하는지(인체 그림), 학습 곡선, 오차 분포, 체형·나이별 오차 |

모든 장에 발표자 노트(대본)가 있습니다.

## 먼저 읽을 것: 넣은 값은 옷 사이즈가 아니라 몸 치수입니다

사이즈코리아에는 "평소 입는 바지 사이즈" 같은 항목이 없습니다. 그래서 평가에 넣은 값은 **몸 치수를 옷 표기 단위로 반올림한 것**입니다
(045 허리둘레 → 1인치, 043 젖가슴아래둘레 → 5cm, 042 − 043 → 2.5cm). 바지·브라 표기 사이즈를 넣은 것이 아닙니다.
표기 사이즈로 대신할 수 있는지는 검증하지 않았고, 대신 어긋날 때를 흉내 낸 민감도 분석을 넣었습니다.

045 허리둘레는 허리옆점 높이(옆구리가 가장 들어간 자연 허리)에서 잰 값이라 바지 허리선보다 위입니다.
배꼽 높이 둘레(046)는 그보다 평균 남 1.9cm · 여 5.4cm 큽니다.

## 요약

데이터는 #5와 같습니다: 사이즈코리아 8차(2020) 직접측정 5,092명, 088 어깨사이너비 · 042 젖가슴둘레 · 045 허리둘레, seed 42로 80/20 분할.
일치율 = 실제 치수를 넣은 `size_fit.recommend` 와 같은 사이즈를 고른 비율 (평가용 1,019명 × 치수표 9개 = 9,171쌍, #5의 "한 점"과 같은 정의).

**1. 선형 회귀 학습 정리**
- 평균만 찍기 대비 오차(평가용 20%): 가슴 남 5.11 → 2.35cm · 여 6.66 → 2.55cm, 허리도 절반 이하. 어깨는 약 20%만 줄어듭니다(R² 0.32~0.34).
- 학습 인원을 160명으로 줄여도 전체로 배운 것과 0.04cm 이내입니다. 남은 오차는 데이터 부족이 아니라 **입력 부족**입니다 (#6 의 MLP 결과와 같은 이야기).
- 나이가 식에 없어서 허리 예측이 연령 구간에 따라 최대 3~4cm 치우칩니다.

**2. 몸 치수를 정확히 안다면 (상한)**

| 아는 값 | 전체 일치율 |
|---|---:|
| 키·몸무게 (#5) | 84.2% |
| + 나이 | 85.8% |
| + 발길이(신발 단위) | 84.0% |
| + 허리둘레(1인치 단위) | 91.0% |
| 남: + 허리둘레 / 여: + 허리둘레 + 밑가슴둘레 + 가슴−밑가슴 차 | 92.0% |
| + 허리둘레 + 가슴둘레(1cm 단위) | 97.7% |

- 후보 7개(나이·허리·밑가슴·가슴 차·발길이·목둘레·머리둘레)의 모든 조합 90개를 비교했습니다. 변수 5개까지 채워도 나이·발길이·목둘레·머리둘레는 0.3%p 이내입니다.
- **남자 상의는 81.5 → 82.5%에서 멈춥니다.** 가슴둘레를 알면 97.9%입니다.

**3. 허리둘레를 "바지 표기 사이즈"로 대신하면 (민감도 분석, 하의 일치율)**

| 표기와 실제 허리의 관계 | 남 | 여 |
|---|---:|---:|
| 허리를 안 물을 때 (기준) | 82.6% | 72.6% |
| 실제 허리둘레를 1인치 단위로 정확히 앎 | 97.6% | 94.5% |
| 표기가 1인치 큼 | 85.6% | 71.0% |
| 표기가 2인치 큼 | 79.6% | 52.9% |
| 표기 = 배꼽 높이 둘레(046) | 86.9% | 55.1% |
| 위 + "표기 → 허리" 보정식을 따로 학습 | 91.4% | 83.4% |
| 사람마다 ±1인치 흔들림 | 87.2% | 78.0% |

- 표기가 1인치만 어긋나도 하의의 이득이 거의 사라지고, 여자는 허리를 안 물을 때보다 낮아집니다.
- 브라 표기는 덜 민감합니다: 여자 상의 96.4% → 한 단계씩 틀려도 93.4~95.6% (안 물을 때 92.8%).

**결론: 정확도를 올리는 것은 옷 사이즈가 아니라 몸 치수(허리둘레·가슴둘레)입니다.**

## 한계

- 민감도 분석의 어긋남 크기(±1·2인치, 절반이 한 단계)와 "배꼽 높이 = 바지 입는 높이"는 제가 정한 가정입니다. 실제로 표기가 얼마나 어긋나는지는 모릅니다.
- 키·몸무게를 틀리게 말하는 오차는 넣지 않았습니다.
- 정답은 "치수를 알 때의 추천"이지 실제로 입어서 맞는지가 아닙니다.
- 원자료의 연령 코드(1~10)가 나이순 구간이라는 것은 추정입니다.
- 확률 추천(60% 기준)은 새 변수로 다시 돌리지 않았습니다. 위 수치는 예측값 한 점 기준입니다.
- 평가 스크립트는 개인 작업 폴더에 있고 이 PR에는 넣지 않았습니다(필요하면 따로 올리겠습니다).

## 팀에서 정할 것

1. 팀원의 "평소 바지·브라 표기 vs 줄자(045·046·042·043)"를 재 볼지 — 표기 사이즈를 쓸 수 있는지는 이것으로만 알 수 있습니다.
2. 표기 사이즈에 보정식을 붙일지, 확률이 낮은 사람에게 줄자 한 곳(하의는 허리, 상의는 가슴)을 요청하는 #5 방식을 유지할지.
3. 나이를 입력으로 넣을지 (#6 제안과 같음). 효과는 하의 쪽에 있고 상의는 거의 그대로입니다.
4. 어깨 정의(#6 의 1번): 제 학습 데이터에서도 088 남자 평균은 39.7cm입니다.

사이즈코리아 원자료와 개인 사진은 포함하지 않았습니다. 발표 파일의 산점도는 원자료를 점으로 그린 그림이고, 인체 그림은 설명용 도식입니다.
